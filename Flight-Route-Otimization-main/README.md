# Flight-Route-Otimization
The Flight Route Optimization System is a Java-based application that efficiently determines the best air travel routes between major cities by applying core concepts of Data Structures and Algorithms (DSA). In this system, airports are represented as nodes, and flight connections are modeled as weighted edges within a graph structure. By using efficient data representations such as adjacency lists, hash maps, and priority queues (min-heaps), the system ensures fast and accurate route computations.

To find the most optimal travel path, the system implements Dijkstra’s Shortest Path Algorithm, which calculates the minimum distance between two selected cities. This algorithmic approach enhances route planning, reduces travel time and cost, and demonstrates how computational techniques can support real-time decision-making in aviation networks. Overall, the system showcases the practical application of DSA in solving real-world transportation problems through efficient graph-based modeling and optimization.
